Это микросервисный проект для управления задачами пользователей. Система состоит из сервисов авторизации, гейтвея, задач, планировщика, уведомлений и сервера обнаружения. Для хранения данных используются базы данных PostgreSQL и кэш Redis. Обмен событиями между сервисами выполнен через брокер сообщений Kafka. Для безопасной отправки событий применён паттерн Transactional Outbox. Все сервисы упакованы в Docker и запускаются через docker-compose.
